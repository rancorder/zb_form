Overview

このシステムは何をする？

企業リストへ「お問い合わせフォーム営業」を、チームで重複なく・抜けなく回すための仕組みです。リストの取り込みから、作業者への自動振り分け、進捗・報酬の締めまでを1か所で管理します。

🧑‍💻 作業者

表示された1社ずつ、フォームから営業 → 配信OK / NG を記録するだけ。次の会社は自動で出てきます。

🔎 運営者

反応のあった企業を検索し、1次・2次対応を記録します。

📊 管理者

リスト取り込み・進捗確認・報酬の締め（OK 5円 / NG 1円）・トラブル対応を担当。

Flow

全体の流れ

① 取り込み

管理者が担当者ごとのリストを取込元フォルダへ。担当者は自動で付与、重複・NG企業は自動除外。

② 作業

作業者が1社ずつフォーム営業し OK/NG を記録。終わると自動で次へ。

③ 締め

管理者がダッシュボードで進捗と報酬を確認。作業者ごとの金額が出ます。

各画面はURL末尾で切り替わります。?page=worker 作業者　?page=operator 運営者　?page=dashboard 管理ダッシュボード

Steps

本番の手順

1

自分の画面を開く

配られた ?page=worker のURLを開く。スマホでもOK。

2

名前を選んで「作業開始」

担当者プルダウンから自分の名前を選んでスタート。

3

会社を確認してフォームを開く

「企業サイト」「お問合せフォーム」を開く。フォームが無い会社は自動でGoogle検索リンク（公式サイト・所在地・SES・問合せ）が出ます。

4

送信できたら「配信OK」

フォーム送信が完了したら緑の配信OK。時刻は自動で備考へ記録されます。

5

ダメなら「配信NG」＋理由

フォームが無い・お断り等は赤の配信NG→理由を選ぶ（または自由入力）。

6

自動で次へ。終わりは完了画面🎉

記録すると次の1社が自動表示。中断は「停止」で未に戻して終了。全件終わると完了画面が出ます。

⚠️
画面を閉じる前に「停止」を。 作業途中でそのまま閉じると、その会社は「作業中」のまま残ります（30分後に自動で未へ戻りますが、停止を押すのが確実）。

Reward

② 報酬を確認する

締めのときは ?page=report を開くだけ。作業者ごとの OK・NG と金額が出ます（配信OK 5円 / NG 1円）。

💰 報酬ページ

?page=report ― 担当者別の OK / NG / 報酬と合計。そのまま作業者へ共有できます。

📊 ダッシュボード最下部

?page=dashboard ― 進捗と一緒に見たいとき。一番下に同じ報酬表が出ます。

Troubleshooting

こまったとき

よくある詰まりどころと直し方。

🌀 会社が「作業中」のまま残る

作業者は画面の「停止」を押す → 未に戻ります。管理者はダッシュボードの「再開放」、またはメニュー「期限切れ作業を再開放」。放置でも30分後に自動で未へ。

💰 報酬集計が出ない

トップ画面ではなく「管理ダッシュボード」を開いて一番下までスクロール。または ?page=report を直接開く。コード変更後は必ず新バージョンで再デプロイ。

📥 リストが取り込まれない

ファイルを「取込元フォルダ」の中に置いたか確認。ファイル名に → が入っていないか、企業名の列があるか、形式がスプレッドシート/Excelか。

🧑‍💻 担当者名がプルダウンに出ない

「作業者」シートのA列に名前を追加 → UIをリロード。表記は取り込みファイルの 【名前】 と揃える。

🔁 直したのに反映されない

ほぼ再デプロイ漏れ。「デプロイ → デプロイを管理 → 編集 → バージョン＝新バージョン → デプロイ」。

↩️ 間違えて記録した

運営者UI ?page=operator で企業名検索 → 状態を確認・修正。1次/2次対応は何度でも上書き可。
